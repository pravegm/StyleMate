# Working agreements for StyleMate

## Documentation
- **Keep the README honest in the same commit.** Whenever a change alters
  user-facing behavior or setup — architecture, any on-device ML model, the
  weather provider, permissions, or the build/setup steps — update
  `README.md` in that same commit. Pure bugfix/internal commits don't need it.
  Before pushing such a change, sweep the README for stale references.

## Delivery
- Verify a fix actually builds/works before delivering it. Don't claim a fix
  works on inspection alone. Nobody on the team can run Xcode locally: every
  branch push runs `.github/workflows/ci.yml` (macOS `xcode-27` runner, simulator
  tests with the real models). Green CI is the bar; look at the `ci-report`
  artifact's cutouts for anything visual.
- **The Mac runners are shared by every branch, so spend them deliberately.** A
  feature-branch push runs unit tests + the Release compile only (~45 min). Commit
  message tags: `[tests: StyleMateTests/TryOnTests, ...]` runs only those unit tests
  (minutes, not 45); `[ui]` or `[full]` adds the UI tests + `e2e-screens`; `[skip ci]`
  runs nothing. Docs-only pushes don't run. Each push cancels the branch's running
  CI, so batch commits and push when you want a result, not after every commit.
  Run `duo.yml` once per branch, right before asking for a merge. Merge `origin/main`
  into a branch once, just before that final full run — not after every main merge.

## Fully on-device (founder decision, 4 Nov 2026)
- No cloud AI. No photo, pixel, face or wardrobe data goes to any AI service.
  Garment extraction = `Services/Wardrobe/` (Core ML: GarmentNet + FashionSigLIP);
  outfits = `Services/Outfits/OutfitEngine`. Apple's
  Foundation Models may be used ONLY via `SystemLanguageModel` (on-device),
  never Private Cloud Compute, and always with a silent deterministic fallback.
- All model weights are git-ignored and regenerated by `scripts/build_*_models.sh`
  (CI caches them). Their licences are a launch blocker — see docs/MODEL-LICENSING.md.

## Garment segmentation (GarmentNet — must stay commercially licensed)
- `GarmentNet.mlpackage` = frozen DINOv2 ViT-S/14-reg4 (Apache-2.0) + StyleMate's own head,
  trained from scratch by `.github/workflows/garment-model.yml` (CPU runners) on Fashionpedia
  + COCO person masks (annotations CC BY 4.0). Never train on or distil from DeepFashion2,
  ModaNet, LIP/ATR/CIHP or any non-commercial model (FASHN, SegFormer/MiT weights).
- The head lives only in a workflow artifact; `scripts/garment/model.json` pins the run id and
  sha256 and CI's `models` job downloads + converts it. Retrain: push a commit whose message has
  `[garment-train]` (extract + train) or `[garment-head]` (train only, reusing the chunks of
  `train_config.json`'s `chunks_run`), then pin the new run in model.json.
- Output classes: 0 scene, 1–26 Fashionpedia whole garments (`GarmentSegmenter.fpNames`),
  27 body (person, no garment). `WardrobeML.parse()` maps them to the old FASHN region codes
  for callers that count regions (studio render QC).
- The FASHN / SegFormer converter is kept only as `scripts/research/` (non-commercial, unused);
  CI fails if `GarmentParser` / `GarmentLabeler` reappear in `StyleMate/ML` or the Release app.
- Acknowledgement text: `StyleMate/Resources/Acknowledgements/ACK-12-garment-segmenter.md`.

## Face recognition (the app's USP — must be error-less)
- Embedding model: **AdaFace IR-101 (WebFace12M)**, Core ML fp16 (~125 MB),
  bundled as `MobileFaceNet.mlpackage` (filename kept for history). Regenerate via
  `scripts/convert_adaface.py`. The `.mlpackage` is git-ignored.
- **AdaFace input is BGR** (cv2 convention), `(px-127.5)/127.5`, 112×112 — NOT RGB.
  `createInputMultiArray` feeds B→plane0, R→plane2. A model swap back to an
  InsightFace/ArcFace model must restore RGB.
- **Face detection + 5-point landmarks come from bundled InsightFace SCRFD-10G**
  (`SCRFDDetector`, `SCRFD10G.mlpackage`), NOT Apple Vision — Vision's landmarks
  were too imprecise and collapsed same-person similarity (proven: SCRFD→0.988 vs
  Vision→~0.2). SCRFD input is **RGB**, `(px-127.5)/128`, 640×640 letterboxed
  top-left. It outputs 5 points in canonical ArcFace order, fed to `warpAligned`.
  Regenerate via `scripts/convert_scrfd.py`. Don't reintroduce Vision landmarks.
- Embeddings are model-specific. Persisted galleries are tagged with
  `FaceMatchingService.modelVersion`; a mismatch auto-discards and rebuilds from
  the selfie. Bump that constant on any model swap.
- Matching is cosine similarity with tiered confidence + runner-up margin.
  Auto-scan identity resolution is strict (high confidence + clean margin) and
  isolates the user's garments via a person-instance mask so other people's
  clothes are never extracted. Keep upload / camera / auto-scan consistent.

## Secrets
- The app has no API keys any more. `StyleMate/Secrets.swift` (git-ignored) is
  a leftover; never commit it.
